# Udit Narayan Porwal — Personal Website

A responsive black-and-gold personal portfolio starter, designed for mobile and desktop.

## Included
- Homepage, About, Projects, Highlights, Journal and Contact sections
- Responsive mobile navigation
- SEO title, description and social sharing metadata
- `/admin/` starter for Decap CMS, intended to let you publish journal posts without editing the site code

## Before publishing
1. Replace the sample text, email, and social links in `index.html`.
2. Replace the photo placeholder with your own image (or ask for help doing this).
3. Create a GitHub account and a new repository for these files.
4. Import the repository into Netlify and deploy it.
5. Configure the CMS authentication. The `/admin/` page is only a CMS interface until the Git Gateway/authentication setup is completed. Do not share passwords or verification codes.
6. Test publishing a post before relying on it.

## Free hosting and Google
Netlify's free tier can host a static website, subject to its current limits and terms. Google indexing is free but not guaranteed; after launch, verify the site in Google Search Console and submit a sitemap when one is added.

## Important note about editing
The portfolio text and design are currently edited in the files. The CMS starter is configured for journal/blog posts. A full visual editor for every homepage section needs additional setup or a different CMS integration.
